# 🧪 Shoes Store 測試指南

## 啟動專案

```bash
npm run dev
```

開啟瀏覽器訪問：http://localhost:3000

---

## 🔐 1. 身份驗證測試

### 註冊新帳號
1. 點擊右上角 **Sign In** 或前往 `/sign-up`
2. 填寫資訊：
   - Name: 你的名字
   - Email: test@example.com
   - Password: 至少 6 個字元
   - Confirm Password: 相同密碼
3. 點擊 **Sign Up**
4. ✅ 應該自動登入並導向首頁

### 登入現有帳號
1. 前往 `/sign-in`
2. 使用範例帳號（seed 資料）：
   - Email: `admin@example.com` (如果有在 sample-data.ts 中)
   - Password: 查看 `db/sample-data.ts` 中的密碼
3. 或使用剛註冊的帳號
4. ✅ 登入成功後應顯示使用者名稱

### 登出
1. 點擊右上角使用者選單
2. 選擇 **Sign Out**
3. ✅ 應該回到首頁並顯示 Sign In 按鈕

---

## 🛍️ 2. 商品瀏覽測試

### 首頁
1. 訪問 http://localhost:3000
2. ✅ 應該看到精選商品
3. ✅ 商品卡片應顯示：
   - 圖片
   - 名稱
   - 價格
   - 評分

### 商品詳情頁
1. 點擊任一商品
2. ✅ 應該進入 `/product/[slug]` 頁面
3. ✅ 應該顯示：
   - 商品大圖
   - 名稱、品牌、類別
   - 價格
   - 描述
   - 庫存狀態
   - 顏色選項
   - 尺寸選項
   - 加入購物車按鈕

---

## 🛒 3. 購物車測試

### 加入購物車
1. 在商品詳情頁選擇顏色和尺寸
2. 點擊 **Add to Cart**
3. ✅ 應該顯示成功訊息
4. ✅ 購物車圖示應顯示數量

### 查看購物車
1. 點擊右上角購物車圖示或前往 `/cart`
2. ✅ 應該看到剛加入的商品
3. ✅ 顯示：商品圖、名稱、價格、數量

### 更新數量
1. 在購物車頁面調整商品數量
2. ✅ 總價應該即時更新

### 移除商品
1. 點擊商品旁的刪除按鈕
2. ✅ 商品應該從購物車移除
3. ✅ 總價應該更新

---

## 📦 4. 結帳流程測試

### 前提：購物車中有商品且已登入

### Step 1: 運送地址
1. 從購物車點擊 **Proceed to Checkout**
2. 前往 `/shipping-address`
3. 填寫：
   - Full Name
   - Street Address
   - City
   - Postal Code
   - Country
4. 點擊 **Continue**
5. ✅ 應該導向付款方式頁面

### Step 2: 付款方式
1. 在 `/payment-method` 頁面
2. 選擇付款方式：
   - PayPal
   - Stripe
   - CashOnDelivery (貨到付款)
3. 點擊 **Continue**
4. ✅ 應該導向訂單確認頁面

### Step 3: 確認訂單
1. 在 `/place-order` 頁面
2. ✅ 檢查顯示：
   - 運送地址
   - 付款方式
   - 訂單商品列表
   - 價格明細（商品、運費、稅金、總計）
3. 點擊 **Place Order**

### Step 4: 訂單完成
1. ✅ 應該建立訂單
2. ✅ 導向 `/order/[id]` 訂單詳情頁
3. ✅ 購物車應該清空

---

## 💳 5. 付款測試（PayPal）

### 注意：需要設定 PayPal credentials

如果有設定 PayPal：
1. 在訂單詳情頁應該看到 PayPal 按鈕
2. 點擊 PayPal 按鈕
3. ✅ 應該彈出 PayPal 付款視窗
4. 使用 PayPal Sandbox 測試帳號付款
5. ✅ 付款成功後訂單狀態應更新為 "Paid"

如果選擇 CashOnDelivery：
1. ✅ 訂單顯示為 "未付款"
2. ✅ 顯示貨到付款資訊

## 🔍 8. 錯誤處理測試

### 未登入訪問受保護路由
1. 登出狀態下訪問 `/shipping-address`
2. ✅ 應該重定向到登入頁面

### 空購物車結帳
1. 清空購物車
2. 嘗試訪問 `/shipping-address`
3. ✅ 應該重定向回購物車或顯示錯誤

### 表單驗證
1. 嘗試提交空的註冊表單
2. ✅ 應該顯示驗證錯誤訊息

### 庫存不足
1. 嘗試加入超過庫存數量的商品
2. ✅ 應該顯示庫存不足訊息

## 🐛 常見問題

### 無法連接資料庫
- 檢查 Docker PostgreSQL 是否運行：`docker ps`
- 檢查 `.env` 中的 `DATABASE_URL`

### 商品圖片不顯示
- 檢查 `next.config.ts` 中的 `remotePatterns`
- 確認圖片 URL 正確

### NextAuth 錯誤
- 確認 `NEXTAUTH_SECRET` 已設定
- 檢查 `NEXTAUTH_URL` 是否正確

### Prisma 錯誤
- 執行 `npx prisma generate`
- 重新啟動開發伺服器
